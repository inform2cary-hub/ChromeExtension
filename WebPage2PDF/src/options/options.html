5. How it works

    
    
      
  • Export uses Chrome’s own print engine (CDP Page.printToPDF), so the output is real selectable, searchable text — not a screenshot.
    • 
      
  • Reaching that engine requires the “debugger” permission. Chrome shows a “debugging this browser” bar at the top of the tab while exporting; it disappears when the export finishes.
    • 
      
  • If DevTools is already open on that tab the export fails because only one debugger can attach. Close DevTools first.
    • 
      
  • Chrome’s built-in pages (chrome://), extension pages and the Chrome Web Store cannot be exported. That is a browser restriction.
    • 
      
  • For pages that refuse to export, open “Other ways” in the popup and use Chrome’s print dialog instead.
    • 
    

  


  

    Settings save automatically.
